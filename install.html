Free and open source. No account, no telemetry, no network requests.

This download is for Chrome 102+ and Edge 102+.

Install in 4 steps

  1. 1

    Download the archive

    Click the button above to save the ZIP file.

  2. 2

    Unzip it

    Right-click the file and choose Extract All, or use any archiver. The extracted folder contains manifest.json.

    Do not delete or move that folder afterwards.

  3. 3

    Open the extensions page

    Paste the address below into the address bar and press Enter.

    chrome://extensions
  4. 4

    Load the folder

    Turn on Developer mode (top-right), click Load unpacked, and select the extracted folder.

How to use

  • Click the extension icon, then pick a mode.
  • For a selection, drag a box. Esc cancels.
  • The stitched result opens in a new tab.
  • Every tool from this site sits in the same popup.

Keyboard shortcuts:

  • Alt+Shift+FCapture entire page
  • Alt+Shift+VCapture visible area
  • Alt+Shift+SCapture selection

Good to know

  • Browser-internal pages cannot be captured.
  • A developer-mode warning after restart is harmless.
  • It will not update itself automatically.

Your images never leave your device.
